# Enchères

A web auction application built as a layered back-end project for the ENI course "Projet - Réaliser une application web Back End structurée en couches".

## About The Project

This project is an auction (enchères) web application developed as part of the ENI training program, focused on building a structured, layered back-end web application.

The original README (in French) listed the status as "En cours" (in progress).
